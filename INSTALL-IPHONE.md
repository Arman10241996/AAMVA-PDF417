# Install on iPhone

1. Host this folder on any HTTPS web host.
2. Open the app URL in **Safari** on the iPhone.
3. Tap the **Share** button.
4. Tap **Add to Home Screen**.
5. Tap **Add**.

The app will then appear on the Home Screen and launch in standalone mode.

## Important
iOS does not allow a PWA to be installed directly from a ZIP file or from a local `file://` URL.
The folder must be served over HTTPS for Home Screen installation and service-worker caching.
